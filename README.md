A photorealistic close-up of a gourmet smash cheeseburger: a glossy sesame brioche bun, molten cheddar dripping down a thick charred beef patty, caramelized onions, ripe tomato and crisp lettuce, in warm golden side light on dark slate — made to make you hungry at a glance.

## Run it

```sh
python3 main.py
```

The program copies the shipped `entry.png` (1024×1024 JPEG, 255,210 bytes) byte-for-byte to `/output/entry.png` (`MAKEFUN_OUTPUT_DIR` stands in for `/output` outside the grader). No network, no randomness: two runs write identical bytes.
